- **`naming-shortlist.md`** — company/research-arm name exploration (Whetstone leading). Now **secondary**
  to the methodology; retained for when the entity needs a name.
- **`positioning-ideas.md`** — scratch for positioning metaphors. Live idea: "relationship counsellor for
  the human–AI partnership."
